# Инструментальный стеллаж 6000×700×1800

Чертёж для мастера и 3D-модель. Размеры берутся из одного файла `model.js`, поэтому чертёж и модель совпадают.

- `drawing.html`: 3 листа A3 (общий вид, секция и узлы, спецификация), печать в PDF
- `3d.html`: 3D-модель (three.js)
- `stellazh-6000x700x1800.pdf`: те же листы одним файлом
